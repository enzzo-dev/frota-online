How sessions work

      

        
15 min
Access token lifetime. It is a signed JWT carrying your id, e-mail and role.

        
30 days
Refresh token lifetime. It is random, shown once, and stored on our side only as a hash.

        
1 use
Every refresh token works once. Using it again is treated as theft and ends the session.

      

      
Roles are Customer, Driver and Admin. Sign-up only creates the first two. Passwords need 8 to 128 characters with an upper case letter, a lower case letter and a digit.

Renewing an expired session

      
Any authenticated call can answer 401 when the access token expires. Renew it once and repeat the call. Each refresh token works one time, so store the new pair. Sending an old one ends the session.

      

        
  1. Chamada autenticada
    Qualquer endpoint com Bearer
  2. Veio 401?
    não: usa a resposta normalmente
  3. POST/auth/refresh
    Envia o refreshToken guardado
  4. Veio 200?
  5. Repete a chamada
    Só uma vez, com o novo token e o par guardado
    Volta ao login
    Não veio 200: apaga os tokens da sessão

      

    


    

      
Driver onboarding

      
A driver cannot send proposals until an admin approves the profile. These are the calls, in order. Authenticate as a Driver for steps 1 to 6 and as an Admin for step 7.

      

        

          
StepCallWhat happens

          
            
1GET /terms/pending then POST /terms/acceptAccept every active term. Each acceptance stores the time and IP address.

            
2PUT /driver/profileSend taxId (CPF or CNPJ, letters allowed), CNH and category. The tax id is required and checked by its digits before anything is saved. Repeat the call to correct data while the profile is a draft or rejected.

            
3POST /driver/vehiclesRegister at least one vehicle. Plates accept ABC1234 and ABC1D23.

            
4POST /driver/documentsRegister the files you already uploaded. The storage key must start with drivers/{your user id}/.

            
5GET /driver/profileThe checklist shows what is still missing: terms, vehicle, document.

            
6POST /driver/submitMoves the status to PendingReview and locks the profile. An incomplete checklist returns the missing items.

            
7GET /admin/drivers, then approve or rejectThe admin reviews the file. Approval or rejection (with a reason) sends an e-mail. A rejected driver edits and submits again.

          
        

      

      
In Development the API creates an admin on first start (admin@frotaonline.local, password from Seed:Admin:Password in appsettings.Development.json) and publishes version 1.0 of the terms. Sign in with it to try step 7.

Errors

      
Every failure comes back as JSON in the problem details format. Read the status code first, then title for a stable code you can branch on.

      

        

          
A failed request

          
HTTP/1.1 409 Conflict
{
  "title": "auth.email_in_use",
  "detail": "This e-mail is already registered.",
  "status": 409
}

        

        

          
A request with invalid fields

          
HTTP/1.1 400 Bad Request
{
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "Password": ["Password must contain a digit."]
  }
}

        

      

      

        

          
StatusCodeWhat it means and what to do

          
            
400validation_errorA field is missing or invalid. Read the errors object and fix those fields.

            
401auth.invalid_credentialsWrong e-mail or password. The message is the same for both on purpose.

            
401auth.invalid_refresh_tokenThe refresh token is unknown, expired or already used. Ask the person to sign in again.

            
401no bodyThe access token is missing, invalid or expired. Refresh it and retry once.

            
403auth.user_inactiveThe account is disabled. Contact support.

            
409auth.email_in_useThat e-mail already has an account. Send the person to sign in.

            
409driver.profile_lockedThe profile is under review or approved. It can only be edited while draft or rejected.

            
409driver.tax_id_in_use / driver.cnh_in_use / driver.plate_in_useAnother account already registered that document or plate.

            
400driver.submission_incompleteTerms, vehicle or document is missing. The errors object names each one.

            
403no bodyThe signed-in role cannot use this endpoint, for example a Driver calling /admin.
